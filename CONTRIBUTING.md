# Contributing

Please open an issue before starting a large change. For bugs, include the macOS
version, Mac chip, app version and a short way to reproduce the problem. Keep
private clipboard contents, documents, tokens and device pairing codes out of reports.

For development, read [the build guide](docs/development.md). Use native macOS UI,
real system values and explicit opt-ins for clipboard collection or permissions.
Preserve the offline Reader and bundled third-party notices. Run the release build
and relevant self-tests before proposing a change. Do not commit build artifacts,
model binaries, local preferences or credentials.

There is no general open-source license for the original app source yet. Please
agree on contribution and licensing terms with the maintainer before submitting code.
