# What’s new

## 1.0.0

The first release of macino brings the everyday tools into one menu bar app:

- Live system stats, with the values you choose beside the menu bar icon.
- Searchable process groups, sorting and controls for stopping apps.
- Quick Access shortcuts for files and folders.
- Network activity, proxy settings and DNS tools.
- Android file transfer and USB/Wi-Fi screen mirroring.
- An offline Reader for English and Persian text and documents. Normal speed sits
  exactly in the middle of the speed slider.
- Optional clipboard history with a shortcut you choose, search, delete and
  Clear all. Drag any edge of its small window to move it.

The interface and documentation are in English. The Reader keeps its bilingual
label and supports both languages. This build is locally signed; Apple Developer
ID signing and notarization are not included.
